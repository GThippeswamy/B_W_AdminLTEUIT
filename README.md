## 📌 Overview
This project is a **hybrid automation framework** designed to test the **AdminLTE UI dashboard** and **APIs**.  
It ensures **end-to-end validation** of:
- 🌐 **UI components** using Selenium WebDriver.  
- 🔌 **API endpoints** using RestAssured.  
- 🔄 **Data Integrity** by cross-verifying UI data with backend API data.  
- 📊 **Reporting** with ExtentReports + TestNG reports.  

---

## 🔹 Features
- ✅ UI Testing (Forms, Tables, Charts in AdminLTE)  
- ✅ API Testing with Bearer Token Authentication  
- ✅ Data Integrity Testing between UI & API  
- ✅ Configurable `config.properties` file  
- ✅ HTML & TestNG Reports for results
