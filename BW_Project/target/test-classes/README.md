# AdminLTE Sentinel Framework

## Overview
This project automates **AdminLTE v3 dashboard** and **GoREST API** to validate **data integrity** between UI and backend.

## Features
- UI Automation with Selenium + TestNG
- API CRUD automation with RestAssured
- End-to-End Data Integrity Validation
- ExtentReports integration for reporting
